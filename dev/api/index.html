API reference¶

The public API is what neuralopt exports (neuralopt.__all__). Other modules, such as neuralopt.compiled, neuralopt.task_families and neuralopt.fast_training, are research interfaces that may change between minor versions.

minimize ¶

minimize(problem: Problem, mode: Literal['learned', 'certified'] = 'learned', max_evaluations: int | None = None, seed: int = 0, params: Params | None = None, config: ModelConfig = DEFAULT_CONFIG, absolute_gap: float = 1e-06, record_diagnostics: bool = False, model_kind: Literal['transformer', 'mlp', 'gram'] = 'transformer', candidate_method: Literal['direct', 'hamiltonian', 'langevin', 'underdamped', 'preconditioned'] = 'direct', hamiltonian_config: HamiltonianConfig = DEFAULT_HAMILTONIAN_CONFIG, hamiltonian_metric: Literal['identity', 'fixed', 'learned'] = 'learned', fixed_metric_diag: Any | None = None, learned_metric_structure: Literal['diagonal', 'lowrank', 'full'] = 'full', overdamped_config: OverdampedConfig = DEFAULT_OVERDAMPED_CONFIG, underdamped_config: UnderdampedConfig = DEFAULT_UNDERDAMPED_CONFIG, preconditioned_step: float | None = None, preconditioned_engine: Literal['python', 'compiled'] = 'compiled', loop_rule: Literal['halving', 'armijo', 'wolfe'] = 'halving') -> OptimizationResult

Minimize a bounded objective with learned actions or rigorous certification.

Compiled engine¶

preconditioned_solve ¶

preconditioned_solve(objective: Any, x0: Any, bounds: tuple[Any, Any], budget: int, *, theta: Any = None, params: Params | None = None, config: ModelConfig = DEFAULT_CONFIG, model_kind: str = 'transformer', geometry: str = 'learned', structure: str = 'full', fixed_metric_diag: Any = None, preconditioned_step: float | None = None, loop_rule: str = 'halving') -> dict[str, Any]

Run one compiled solve; returns host arrays (see :class:_State) plus status.

objective must be JAX-traceable: objective(x), or objective(x, theta) when theta is given. It is a static argument: reuse the same function object to reuse the compilation.

preconditioned_solve_batch ¶

preconditioned_solve_batch(objective: Any, thetas: Any, x0: Any, bounds: tuple[Any, Any], budget: int, *, params: Params | None = None, config: ModelConfig = DEFAULT_CONFIG, model_kind: str = 'transformer', geometry: str = 'learned', structure: str = 'full', fixed_metric_diag: Any = None, preconditioned_step: float | None = None, loop_rule: str = 'halving') -> dict[str, Any]

vmap the compiled solve over tasks objective(x, theta_i) of one dimension.

thetas, x0 and both bounds carry a leading task axis. Errors are not raised: inspect status per task (see :data:STATUS_MESSAGES).
