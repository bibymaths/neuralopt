# NeuralOpt v0.5.0

Released 2026-11-20 (UTC merge date) · PR #5 · [commits](https://github.com/bibymaths/neuralopt/compare/v0.4.0...v0.5.0)

> Scale-aware, bounded learned geometry evaluated on 30 held-out instances; it did not beat a validation-tuned fixed geometry. Result type: negative.

This release was tagged retroactively on 2026-11-22; it was not published to PyPI.

## Highlights

- Exact reproduction of v0.4 and reconciliation of its two reported FP results.
- A diagnosis: the v0.4 features discarded the gradient norm, so geometry could not
  adapt to objective scale.
- A held-out comparison with disjoint validation tuning, at unseen dimensions 7, 8
  and 10.

## Features

- Opt-in bounded log gradient-scale feature in place of the constant feature, using the
  same input width.
- Bounded geometry for new checkpoints: diagonal bounded in log space; low-rank factor
  normalized by dimension and rank and bounded with `tanh`. Legacy checkpoints behave as
  before.
- Diagonal-only, low-rank-only and full geometry heads as explicit ablations.
- Temperature and friction sampled from their inference ranges during training;
  optional multi-key pathwise meta-gradients.
- Scripts: `scripts/run_transfer_geometry_v0_5.py` and
  `scripts/run_geometry_diagnostics_v0_5.py`.

## Research results

Negative: learned geometry did not beat the validation-tuned fixed geometry overall.

- 30 held-out instances, budget 100; paired mean `log1p(regret)` against tuned fixed
  geometry, positive is worse (`results/transfer-geometry-v0.5.0.json`).
- Overdamped learned full: +0.088 [0.021, 0.164]; learned FP: +0.079 [0.009, 0.178];
  learned low rank: +0.315 [0.065, 0.609].
- BAOAB learned diagonal +0.053 [−0.247, 0.353] and full +0.058 [−0.204, 0.322].
- Learned geometry helped isotropic tasks but regressed on ill-conditioned and rotated
  quadratics (and, for BAOAB, Rastrigin).
- A 36-update checkpoint was also worse, so training budget alone does not explain the
  result. FP regularization did not establish an improvement.
- Diagnosis: a single gradient cannot identify rotated curvature; the limitation is
  information, not positive definiteness.

Report: [transferable geometry](../research/transferable-geometry.md).

## Fixes

- v0.4 reproduced exactly (`results/geometry-diagnostics-v0.5.0.json`). Its two
  overdamped FP − regret values came from two checkpoint generations; the corrected
  −0.048 [−0.105, −0.006] supersedes the pre-review −0.089 [−0.181, −0.008].

## Breaking changes

None. Legacy checkpoint behavior is preserved.

## Known limitations

- One meta-training seed and 30 final instances; six instances per family, so family
  means are diagnostic only.
- Objective closures are compiled independently, and transformer overhead remains
  material.
- Timings are single-host and descriptive.
- The retroactive release workflow does not rerun the test suite at this tag.
