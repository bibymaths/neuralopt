# NeuralOpt v0.6.0

Released 2026-11-21 (UTC merge date) · PR #6 · [commits](https://github.com/bibymaths/neuralopt/compare/v0.5.0...v0.6.0)

> Opt-in secant-history features and a shared preconditioned loop, tested in a pre-registered multi-seed study; an untrained Barzilai–Borwein step beats every learned arm by about one decade. Result type: negative.

This release was tagged retroactively on 2026-11-22; it was not published to PyPI.

**No sdist or wheel.** At this commit `pyproject.toml`, `neuralopt.__version__` and
`CITATION.cff` still read 0.5.0, so a build would be mislabelled. This GitHub release has
no build files; use the git tag or the source archive.

## Highlights

- `history-v1` trajectory features built only from actually evaluated states.
- One preconditioned loop shared by every arm, with objective and gradient calls charged
  to one budget.
- A golden regression test pins v0.1–v0.5 checkpoints and inference outputs.
- A pre-registered study: three training seeds per arm, 84 final-test tasks at unseen
  dimensions 7/10/16.

## Features

- `neuralopt.trajectory`: a fixed-shape buffer of normalized `(u, g_u, f)` records.
  Rejected candidates only increment a counter. Masked secant pairs and twelve
  scale-invariant, permutation-equivariant curvature and reliability features.
- `ModelConfig(feature_set="history-v1", history_length=K)` with checkpoint schema
  `neuralopt-policy/v0.6-history-v1`. Unknown, stripped or inconsistent schemas fail
  closed; legacy files are written byte-compatibly.
- `minimize(..., candidate_method="preconditioned")`: hard acceptance, step halving after
  rejection, no Hessian-vector products. Negative `sᵀy` is reported, never inverted.
- `train(..., objective="history")`: a `lax.scan` mirror of the loop, tested equal to
  inference.

## Research results

Negative: an untrained Barzilai–Borwein (BB) step beats every learned arm by about one
decade, and attention adds nothing over an MLP.

- tf-h8 − BB on the curvature domain: +0.92 [+0.59, +1.25] (positive means BB is
  better). L-BFGS-B leads by about six decades.
- H1 supported: history plus a rejection signal beats a matched no-history control,
  −0.54 [−0.80, −0.32]. The control also drops the rejection counter, so the value of
  secant pairs alone is not isolated.
- H2 not supported: tf-h8 − mlp-h8 = −0.08 [−0.20, +0.06].
- H3 not supported under the 3.5× anisotropy cap: tf-h8 beats the tuned fixed step on the
  curvature domain (−0.22 [−0.43, −0.03]) but fails the reliability guard on Rastrigin
  (+2.39) and Ackley (+0.82). Fixed geometry stays the default.
- Results: `results/trajectory-curvature-v0.6.0.json` (6,300 rows, reproduced exactly).

## Breaking changes

None. v0.1–v0.5 checkpoints and outputs are pinned by the golden test.

## Known limitations

- The geometry parameterization caps off-axis anisotropy at about 3.5×; rotated κ=100–1000
  needs 100–1000×, so H3 is a weaker test than the research question.
- Training used a 50-unit budget feature and evaluation used 100; the bias on H3 and the
  BB comparison was not measured.
- Three training seeds make the seed level of the bootstrap coarse.
- Rosenbrock replicates are near-duplicates, and Rastrigin and Ackley start inside the
  global basin, so global search is not tested.
- Stochastic methods reject history configurations; stochastic history geometry was not
  started.
- The retroactive release workflow does not rerun the test suite at this tag.
