# Citing NeuralOpt

If you use NeuralOpt, please cite **the exact version or commit** you used. NeuralOpt is
an alpha research package; it makes no performance claims, and several of its research
results are negative (see the [release notes](release-notes/index.md)).

The machine-readable source is
[`CITATION.cff`](https://github.com/bibymaths/neuralopt/blob/main/CITATION.cff); GitHub's
"Cite this repository" button renders it.

NeuralOpt is archived on Zenodo from v0.7.0 on. The **concept DOI**
[10.5281/zenodo.24444016](https://doi.org/10.5281/zenodo.24444016) always resolves to the latest archived
version. Each release also has its own **version DOI**, listed on its Zenodo record; cite
that one to pin an exact version.

| Field | Value |
|---|---|
| Title | NeuralOpt: a JAX research package for learned optimization, with replayable interval certification |
| Version | 0.7.0 |
| DOI (concept, all versions) | [10.5281/zenodo.24444016](https://doi.org/10.5281/zenodo.24444016) |
| Author | Mishra, Abhinav (Independent Researcher), ORCID [0009-0005-3179-7408](https://orcid.org/0009-0005-3179-7408) |
| Repository | <https://github.com/bibymaths/neuralopt> |
| Documentation | <https://bibymaths.github.io/neuralopt/> |
| License | MIT |

## BibTeX

```bibtex
@software{mishra_neuralopt,
  author  = {Mishra, Abhinav},
  title   = {{NeuralOpt: a JAX research package for learned optimization, with replayable interval certification}},
  version = {0.7.0},
  year    = {2026},
  url     = {https://github.com/bibymaths/neuralopt},
  license = {MIT},
  note    = {ORCID 0009-0005-3179-7408},
  doi     = {10.5281/zenodo.24444016}
}
```

When citing a commit rather than a release, replace `version` with the commit hash
and add the date you used it.
