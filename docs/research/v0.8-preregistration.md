## 4. Arms (frozen settings)

All arms share the same instances, float64, CPU, the counted unit budget (objective +
gradient calls; objective and gradient reported separately) and the success tolerance
`f − f* ≤ 1e-6 + 1e-3·|f*|`.

| Arm | Frozen setting |
|---|---|
| A0 | family default start; owned L-BFGS (`neuralopt.lbfgs`, memory 10, gtol 1e-8, Armijo c1 1e-4, shrink 0.5) |
| A1 | family default start; **SciPy L-BFGS-B with ftol = gtol = 0, maxfun = budget/2, maxcor 10** (2 units per call) |
| A2 | SciPy multistart, same SciPy settings; starts are scrambled Sobol (seed 3); K per budget chosen on validation from {2, 4, 8, 16} (§9 lists the chosen K) |
| A2o | owned multistart; same starts; K chosen on validation from {2, 4, 8, 16} |
| A3 | nearest-neighbour start (F0's features: observations interpolated to a common grid per species, standardized with training statistics, dose appended; labels from owned multistart, 16 starts × 1,000 units); owned L-BFGS |
| A4 | the learned start `g_φ` (§5): the highest-confidence candidate; owned L-BFGS |
| A4K | the top-K candidates by confidence, budget split equally across starts; owned L-BFGS. K = 4 is primary; 1, 2 and 8 are exploratory |
| A4F | A4 plus fallback to A2o (K = 2, the rest of the budget) when the confidence is below `τ_c` or the refined fit fails the fit check; fallback units count |
| A5 | A4's start with SciPy refinement (harness only; separates start from refinement) |

- **Default-tolerance SciPy** (A1 and A2 with SciPy's defaults) is run and reported as
  context only. It decides nothing.
- **Reference optimum `f*`:**
  - F0's protocol: SciPy L-BFGS-B multistart, 64 Sobol starts plus the truth, two seeds,
    2,000 units each, ftol 1e-15 and gtol 1e-10.
  - It is updated, and the update reported, whenever any arm finds a lower value beyond
    tolerance.
  - Two-seed reproduction is reported. If it falls below 99% on a split, the reference
    budget is doubled for that split before any claim is evaluated.

## 5. The start predictor `g_φ` and its training (frozen)

- **Input:** each observation is a token `(t/10, standardized y, species one-hot,
  log σ, dose)`, where y is standardized with training-split statistics per species.
  Padding is masked.
- **Encoder:**
  - a linear embedding to width 64;
  - 2 transformer blocks with 4 heads, masked self-attention and pre-layer-norm, GELU MLP
    of width 128;
  - masked mean pooling concatenated with attention pooling (one learned query).
- **Heads:**
  - **K = 8 candidates:** a 2-layer MLP (width 128) outputs 8 × 4 values. Each is mapped
    into the optimization box by `lo + (hi − lo)·(tanh(·) + 1)/2`. The box is in the
    family's own coordinates: log parameters for the cascades.
  - **Confidence:** for each candidate, a 2-layer MLP (width 64) on the pooled embedding
    and the candidate gives a probability that owned L-BFGS from that candidate reaches
    success within B.
- **Losses** (two candidate heads, compared in C7):
  - **(R) regression:** best-of-K squared error to the training-target optimum in
    box-normalized coordinates, `min_k ‖u(θ̂_k) − u(θ*)‖²`.
  - **(O) objective-based:** best-of-K objective, `min_k f(θ̂_k; c) / f_scale`, with no
    unrolled steps (k = 0). `f_scale` is the training-split median of `f*`.
- **Training targets:** owned multistart, 16 starts × 1,000 units (the F0 label
  procedure; label adequacy was 100% on validation in every family).
- **Optimizer:**
  - Adam (optax), learning rate 1e-3, cosine-decayed to 1e-5 over 10,000 steps;
  - batch 64 training instances; gradient-norm clip 1.0; float64.
  - Validation loss is checked every 500 steps, and the best checkpoint is kept.
- **Confidence head (stage 2):**
  1. The candidate heads are frozen.
  2. Each training instance's 8 candidates are refined with owned L-BFGS at budget B,
     giving success labels.
  3. The confidence MLP is trained with binary cross-entropy: Adam 1e-3, 2,000 steps,
     batch 256.
- **Diversity check:** the median pairwise box-normalized distance between candidates on
  validation is reported. Below 0.05 is reported as "collapsed". This changes nothing.
- **Seeds:** **5 training seeds (0–4)** per family and loss. Each instance's outcome is
  the mean over seeds; per-seed results and their spread are reported.
- **Validation-only choices,** each made per family before the test is opened:
  - **A4's loss:** (R) or (O), whichever has the higher validation success at B; ties go
    to (R).
  - **Fit check:** `f(θ̂*) ≤ τ_fit`, where `τ_fit` is the 99th percentile of the
    reference optimum `f*` over validation instances.
  - **Confidence threshold:** `τ_c` is the smallest threshold for which A4F's validation
    silent-miss rate is ≤ 0.005 (half the C5 margin). Ties go to the lower fallback rate.
- **Checkpoints:** schema `neuralopt-start/v0.8-v1`, which fails closed. Earlier schemas
  are untouched.

## 6. Metrics

- **Success, units and calls:** as defined in the register's shared definitions.
  Objective and gradient calls are reported separately for every arm, along with the
  pinned-probe gradient/objective cost ratio.
- **B95:** the smallest budget on the grid {25, 50, 100, 200, 400, 800} at which an arm
  reaches 95% success. Its interval comes from bootstrapping the success-versus-budget
  curve over instances.
- **Wall time:**
  - warm, per instance, measured one instance at a time after compilation, on pinned
    single-thread processes on the same machine;
  - cold time (with compilation) and batched time are reported separately.
  - `g_φ` time is included in A4's warm time.
- **Parameter error:** only on instances that the identifiability check (Fisher condition
  ≤ 1e6 at θ*) marks as identified. Non-identified instances are counted.

## 7. Statistics and the joint-claim rule

- **Intervals:**
  - paired over test instances, percentile bootstrap, 95% two-sided, 10,000 resamples,
    bootstrap seed 0;
  - learned arms: instance outcomes are seed means, and seeds are resampled with instances
    (two-level bootstrap).
- **Per-family decisions:** each claim's criterion (§8) is applied **separately per
  family**. The register records one status per family. Within a family, claims that
  require several conditions (C2, C3, C4, C5) are intersection-union tests: every
  condition must hold, and no further correction is applied.
- **Joint claims across families:**
  - Any statement made jointly about several families, such as "the learned start helps
    on the families tested", "on k of 3 families" or a pooled number, uses
    **Holm–Bonferroni over the families it covers**, at a family-wise one-sided level of
    2.5%.
  - Each family's p-value is the largest one-sided bootstrap p-value among the conditions
    of its criterion.
  - Without that correction, results are reported side by side, and **no general claim**
    is made from a single family's win.

## 8. Criteria (copied from the register; amendments marked **[amended]**)

### 8.1 Amendments (decided by the user after F0; they apply where they differ from §8.2)


- **C2 [amended, decision 1]:** **supported** only if, on **both** axes, A4 beats **each**
  required bar:
  - the bars are A0, A3, and the better of A2 and A2o (chosen per axis);
  - on units: the 95% interval of `B95_A4 / B95_bar` lies entirely below 1;
  - on wall time: the 95% interval of warm time A4 / warm time of the bar lies entirely
    below 1.
  - **Not supported** if A4 never reaches 95% within 800 units, or if any ratio's interval
    lies entirely above 1.
  - Otherwise **inconclusive**.
- **C4 [amended, decision 1]:** `N*` is computed against **each** bar, with each bar's own
  offline cost:
  - A0: none;
  - better multistart: none;
  - A3: its label and index cost, so `N*` versus A3 uses the incremental offline cost.
  - **Supported** only if `t_bar − t_A4 > 0`, with an interval lower bound > 0, for every
    bar.
  - **Not supported** ("no break-even") if any bar's interval upper bound is ≤ 0.
  - Otherwise **inconclusive**.
- **C3:** the cost axis already compares against A3. A0 is added as a reported reference
  on that axis; it is not part of C3's criterion, because C2 now carries the A0 bar.
- **C5:** the comparator A2 runs with the full-budget SciPy settings (decision 4).
- **C5 silent-miss bound [amended; stricter than the register, so it never loosens a
  stop]:** the silent-miss rate's 95% upper bound is the exact **Clopper–Pearson** bound,
  not a percentile bootstrap. A bootstrap of a rate near zero degenerates: zero observed
  misses give [0, 0] at any sample size.
- **Matched budget B** is fixed per family as in §2. Every other criterion is unchanged.

### 8.2 Register text at the freeze (verbatim, C1–C10)

### C1. Basin landing

- **Wording:** Learned start + L-BFGS reaches the reference optimum on more instances than
  default start + L-BFGS at the same budget.
- **Test:** A4 versus A0 at budget `B`, owned L-BFGS in both.
- **Criterion (proposed):** **supported** if the paired success-rate difference A4 − A0
  has a 95% interval whose lower bound is > 0.
  - **Not supported** if the upper bound is ≤ 0.
  - **Inconclusive** otherwise.
- **Split:** in-distribution test.
- **Status:** unverified

### C2. Cost versus multistart

- **Wording:** At a matched success rate, learned start + L-BFGS uses fewer units and less
  wall time than multistart L-BFGS-B.
- **Test:** A4 versus the **better of** SciPy multistart (A2) and owned multistart (A2o).
  - "Better" is decided separately on each axis: the lower `B95` for units, the lower warm
    time for wall-clock.
  - The matched rate is 95% success. Compared: `B95` in units, and warm wall time per
    instance at that budget.
  - Cold and batched times are reported as well. Objective and gradient calls are reported
    separately.
- **Criterion (proposed):** **supported** only if it holds on **both** axes:
  - the 95% interval of `B95_A4 / min(B95_A2, B95_A2o)` lies entirely below 1;
  - the interval of warm time A4 / (the better arm's warm time) lies entirely below 1.
  - **Not supported** if A4 never reaches 95% within 800 units, or if either ratio's
    interval lies entirely above 1.
  - Otherwise **inconclusive**.
- **Split:** in-distribution test.
- **Status:** unverified

### C3. The neural part earns its place

- **Wording:** The learned start beats the nearest-neighbour warm start, on both success
  and cost.
- **Test:** A4 versus A3, both refined with owned L-BFGS.
- **Criterion (proposed), a superiority claim:** **supported** only if A4 is **better**
  than A3 on at least one axis (a paired interval excluding zero, in A4's favour) **and
  non-inferior** on the other.
  - **Success axis:**
    - better: the interval of the success difference A4 − A3 at `B` has lower bound > 0;
    - non-inferior: lower bound ≥ −0.02 (−2 percentage points).
  - **Cost axis:**
    - better: the interval of `B95_A4 / B95_A3` has upper bound < 1;
    - non-inferior: upper bound ≤ 1.02. This is the −2 percentage-point margin expressed
      as a relative cost margin.
  - **Not supported** if neither axis shows A4 better (each interval includes zero or
    favours A3), or if A4 is inferior on either axis.
- **If not supported**, this entry must state plainly: **"a nearest-neighbour lookup does
  as well as (or better than) the learned start on this family."**
- **Split:** in-distribution test.
- **Status:** unverified

### C4. Break-even

- **Wording:** The number of instances after which training plus target-solving cost is
  recovered.
- **Test:** `N* = T_offline / (t_generic − t_amortized)`.
  - `T_offline` is the measured wall time of:
    - simulating the training set;
    - solving all training targets (the reference multistart);
    - training, including compilation.
  - `t` is the mean warm time to success at the matched success rate of C2.
  - `t_generic` is the better of A2 and A2o; `t_amortized` is A4, with the `g_φ` forward
    pass included.
  - Batched and per-instance variants are both reported.
- **Criterion (proposed):**
  - **supported** if `t_generic − t_amortized > 0` with an interval whose lower bound is
    > 0. Then `N*` is reported with its interval and the measurement protocol: hardware,
    float64, timing method.
  - **Not supported** ("no break-even") if the interval's upper bound is ≤ 0.
  - **Inconclusive** otherwise.
- **Split:** in-distribution test (timings); offline costs from the actual runs.
- **Status:** unverified

### C5. Safety: no silently missed optima

- **Wording:** With the confidence check and fallback, the success rate is not worse than
  multistart L-BFGS-B.
- **Test:** A4F (fallback included in its units) versus A2, at the larger of the two arms'
  `B95` budgets.
  - **Silent miss** (definition): the fallback was **not** triggered, **and** the final
    fit is worse than the reference optimum by more than the success tolerance, i.e.
    `f(θ̂) − f* > ε_abs + ε_rel·|f*|`.
  - The silent-miss rate is the share of all instances that are silent misses.
- **Criterion (proposed):** **supported** if both hold:
  - the interval of the success difference A4F − A2 has lower bound ≥ −0.01;
  - the silent-miss rate's interval has upper bound ≤ 0.01.
  - **Not supported** if either bound fails decisively: the success upper bound is
    < −0.01, or the silent-miss lower bound is > 0.01.
  - Otherwise **inconclusive**.
- **Split:** in-distribution test; also reported on OOD (C8).
- **Status:** unverified

### C6. Informed versus random multistart

- **Wording:** K informed starts beat K random multistarts at equal K and budget.
- **Test:** A4K versus A2o at the same K and the same total units.
  - **K = 4 is primary.**
  - K = 1, 2 and 8 are **exploratory**: reported, but they do not decide the claim.
- **Criterion (proposed):** **supported** if, at K = 4, the interval of the success
  difference A4K − A2o has lower bound > 0.
  - **Not supported** if the upper bound is ≤ 0. Otherwise **inconclusive**.
- **Split:** in-distribution test.
- **Status:** unverified

### C7. Objective-based versus regression training (secondary)

- **Wording:** Objective-based training beats regression on families with
  non-identifiable directions.
- **Test:** A4 trained with the objective-based loss versus A4 trained with the regression
  loss: same architecture, data, seeds and budget.
  - Applies only to families/variants that F0's identifiability check marks as having
    non-identified directions (expected: 2b). Fisher-information conditioning above a
    pre-registered threshold, or flat profiles.
- **Criterion (proposed):** **supported** if the success difference (objective − regression)
  at `B` has lower bound > 0.
  - **Not supported** if the upper bound is ≤ 0. Otherwise **inconclusive**.
  - If no family qualifies, the status is **inconclusive (not applicable)**.
- **Split:** in-distribution test.
- **Status:** unverified

### C8. Generalization and OOD detection

- **Wording:** Performance on OOD splits is reported, and the confidence score flags OOD
  instances.
- **Test:**
  1. All arms on each OOD split (noise, parameter range, sampling times, dose), with the
     same metrics as the in-distribution test. This part is reported regardless of
     outcome.
  2. The AUROC of `1 − confidence` for separating OOD from in-distribution test instances.
  3. The detection rate (the share of OOD instances below `τ_c`) at the validation-tuned
     threshold.
- **Criterion (proposed):** **supported** if, on every OOD split:
  - part 1 is fully reported;
  - the AUROC interval has lower bound > 0.5;
  - the detection rate is reported.
  - **Not supported** if any split's AUROC upper bound is ≤ 0.5.
  - Otherwise **inconclusive**.
- **Split:** the OOD test splits, plus the in-distribution test as the negative class.
- **Status:** unverified

### C9. Precision is not required

- **Wording:** Basin landing does not require precise predictions. The relation between
  prediction error and success is reported.
- **Test:**
  - **Prediction error:** the distance from the start to θ* in normalized log-parameter
    coordinates.
  - **Reported:** success as a function of error decile for A4, plus a logistic fit, with
    the NN start (A3) on the same axes.
- **Criterion (proposed):** **supported** if the success rate in A4's highest
  prediction-error quartile is ≥ 0.8 × A4's overall success rate, with the interval of
  the ratio having lower bound ≥ 0.8.
  - **Not supported** if the ratio interval's upper bound is < 0.8.
  - Otherwise **inconclusive**.
- **Split:** in-distribution test.
- **Status:** unverified

### C10. The forward pass is cheap

- **Wording:** The forward pass costs negligible time compared with refinement.
- **Test:** warm and cold `g_φ` time versus the warm and cold owned-L-BFGS refinement time
  per instance, single and batched, measured in the same process.
- **Criterion (proposed):** **supported** if the warm ratio (forward / refinement) has an
  interval whose upper bound is < 0.05.
  - **Cold times** (first call, compilation included) are reported for both the forward
    pass and the refinement, single and batched, but do not decide the claim.
  - **Not supported** if the warm ratio's lower bound is > 0.05. Otherwise
    **inconclusive**.
- **Split:** in-distribution test.
- **Status:** unverified

## 11. Outcome reporting

- Every claim gets a per-family status: supported, not supported, inconclusive, or "not
  tested (reason)". Each status comes with its intervals and the numbers behind them.
- A family's results are reported against its §3 expectation. A null result on Family 2a

- Negative results, cost regressions and failed checks are reported as findings.
