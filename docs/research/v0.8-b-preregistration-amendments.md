## Amendment 1 (2026-11-23): retroactive test-first record for the step policy

- **Data seen:** no v0.8-B training has run, and no test split of any track has been opened.
  This amendment changes no criterion, configuration or code path. It records a test
  check and adds one test.
- **Decided by:** the user, who asked for the test-first lapse to be fixed retroactively.
- **The lapse:** `tests/test_step_policy.py` was written before `src/neuralopt/step_policy.py`.
  The tests were not run before the module was written, so nobody saw them fail first.
- **Check 1: tests against a stub, then against the real module.**
  - The stub keeps the public interface and nothing else:
    - `PolicyConfig` and `Window` as data types;
    - every function raising `NotImplementedError`;
    - `POLICY_SCHEMA = ""`.
  - It ran in a scratch worktree of main at ec830a8, imported first through `PYTHONPATH`.
  - **Against the stub: 8 of 8 tests failed.**
  - **Against the real module** (`step_policy.py`, sha256 `adaaf2cc…b41346`): **8 of 8
    passed.**
- **Check 2: mutants of the real module.** A stub only shows that the tests call the
  interface. Single-point mutants show whether they catch wrong behaviour.

  | Mutant | Result |
  |---|---|
  | Rollout charges 1 unit per point instead of 2 | caught (3 rollout tests fail) |
  | Box clip removed from the update | caught (3 rollout tests fail) |
  | Checkpoint schema not checked on load | caught (fail-closed test) |
  | `log σ` unbounded | caught (bounds test) |
  | A coordinate index leaks into the coordinate-mixing layer, varying across the width | caught (permutation test) |
  | The same leak, constant across the width | not caught. It is equivalent: the layer norm removes a constant shift |
  | Empty history slots not zeroed in the tokens | not caught. It is equivalent: the attention mask already excludes them, and the output is read from the newest slot, which is always filled |
  | **Attention mask removed** | **not caught: a real gap.** Empty slots then dilute the attention, and the garbage-fill test cannot see it because the empty tokens are zero in both windows |

- **Fix:** a new test, `test_outputs_do_not_depend_on_the_number_of_empty_slots`. It puts the
  same three states into a 16-slot and an 8-slot window. The parameters do not depend on
  the history length, because there is no positional encoding. It **fails on the
  attention-mask mutant** (4 of 4 outputs differ) and **passes on the real module**, which
  is unchanged. The suite is now 9 tests, all passing.
- No criterion, configuration or frozen number changes.
