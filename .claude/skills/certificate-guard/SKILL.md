name: certificate-guard
description: Protect NeuralOpt interval bounds, fail-closed expressions, and model-independent certificate replay during trajectory and geometry research.
---

If optimization inference only changes, confirm native certification files are unmodified and run existing tests. If candidate injection into certified search is proposed, separate proposal generation from rigorous upper enclosure, lower bound, pruning, domain coverage and certificate replay. Test adversarial invalid incumbent and unsupported operations. Re-run independent replay for every new certified artifact. State the restricted binary64/libm and expression semantics without claiming a stronger formal proof. Never let a neural curvature estimate replace a validated interval bound.
